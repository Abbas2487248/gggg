# Hay Day Smart Manager

مشروع أندرويد أولي لإدارة قائمة مصانع ومنتجات Hay Day محلياً.

## النسخة الحالية
- واجهة عربية RTL.
- قائمة منتجات تجريبية موزعة على مصانع.
- تفعيل وإيقاف متابعة كل منتج.
- إدخال كمية مستهدفة لكل منتج.
- حفظ الاختيارات محلياً على الهاتف.
- الحد الأدنى Android 10 (API 29).

## بناء APK
يعمل GitHub Actions تلقائياً عند كل push إلى فرع main، ويمكن تشغيله يدوياً من تبويب Actions. بعد نجاح البناء، نزّل ملف APK من Artifacts.

## تنبيه مهم
هذا التطبيق حالياً أداة إدارة ومتابعة مستقلة فقط. لا يسجل الدخول إلى Supercell ID، ولا يتصل بخوادم Hay Day، ولا ينفذ التصنيع أو الجمع داخل اللعبة. بيانات المنتجات والأوقات الحالية تجريبية وتحتاج إلى استكمال وتدقيق قبل اعتبارها كتالوجاً كاملاً.
